# Mental Health Awareness Website

A responsive website for mental health awareness and information.

## Project Overview

This is a mental health awareness website built with HTML, CSS, and JavaScript. The site provides information about mental health topics, services, and resources.

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with Bootstrap framework
- **JavaScript** - Interactive elements and animations
- **Bootstrap 5** - CSS framework for responsive design
- **Owl Carousel** - Image and content slider
- **Font Awesome** - Icon library
- **AOS** - Animate On Scroll library

## Features

- Responsive navigation with mobile toggle
- Hero section with call-to-action
- Services/Information sections
- Owl carousel for testimonials or featured content
- Scroll animations with AOS
- Font Awesome icons throughout

## Getting Started

1. Clone or download the project
2. Open `index.html` in a web browser
3. No build process required - static HTML/CSS/JS
